# S3DGen

**Single-Pass Drone Video to 3D Spatial Reconstruction Prototype**

S3DGen is a React and TypeScript-based prototype for transforming drone video into an interactive 3D spatial reconstruction workflow.

The application provides a staged workflow covering video input, frame extraction, frame selection, 3D reconstruction, final model visualization, spatial telemetry, geometric measurements, evidence classification, validation, and scenario-based visualization.

The prototype is designed to make the complete reconstruction process understandable through a structured user interface while keeping the underlying processing workflow organized into distinct stages.

## Features

- Drone/UAV video input and ingestion
- Staged frame extraction workflow
- Frame selection and quality review
- 3D reconstruction workflow
- Interactive 3D model viewport
- Spatial viewport telemetry
- Physical and geometric dimension visualization
- Linear, superficial, and cubic measurement categories
- Evidence classification
- Validation information and reconstruction status
- Disaster and recovery visualization
- Interactive 3D scene controls
- Presentation-oriented workflow interface
- Structured multi-stage processing workflow
- Light professional interface designed for spatial inspection

---

## Reconstruction Workflow

S3DGen organizes the processing experience into a staged workflow:

```text
Drone Video
     ↓
Input Validation
     ↓
Frame Extraction
     ↓
Frame Quality Analysis
     ↓
Frame Selection
     ↓
Feature Analysis
     ↓
Camera / Spatial Estimation
     ↓
3D Reconstruction
     ↓
Point Cloud / Mesh Generation
     ↓
Final 3D Model
     ↓
Visualization and Analysis
```
